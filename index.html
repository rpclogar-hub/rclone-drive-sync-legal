rclone Drive Sync

O rclone Drive Sync é uma ferramenta pessoal de sincronização. Ela usa o programa de código aberto rclone para manter as pastas de um computador iguais às pastas do Google Drive do próprio usuário.

Não é um serviço aberto ao público: é usado por uma única pessoa, apenas com a própria conta Google, para sincronizar os próprios arquivos entre os próprios computadores.

Os arquivos vão direto do computador para o Google Drive. Nenhum arquivo ou dado passa por servidor do desenvolvedor.
