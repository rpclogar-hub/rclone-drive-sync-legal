Política de Privacidade

rclone Drive Sync - última atualização: 07/10/2026

O que o aplicativo faz

O rclone Drive Sync é uma ferramenta pessoal que sincroniza pastas de um computador com o Google Drive do próprio usuário, usando o programa de código aberto rclone.

Acesso aos dados do Google

O aplicativo pede acesso ao Google Drive somente para ler, enviar e organizar os arquivos do usuário que o autorizou, e somente com o objetivo de sincronizar esses arquivos. Esse acesso é usado exclusivamente para essa finalidade.

Coleta, armazenamento e compartilhamento

  • Nenhum dado é coletado pelo desenvolvedor.
  • Os arquivos vão diretamente do computador do usuário para o Google, sem passar por servidor do desenvolvedor.
  • As credenciais de acesso ficam guardadas apenas no computador do usuário.
  • Nenhum dado é vendido, alugado, compartilhado com terceiros nem usado para publicidade ou para treinar modelos de inteligência artificial.

Uso de dados do Google (Limited Use)

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.
